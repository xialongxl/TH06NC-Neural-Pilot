## Software and operation

The software is experimental. Model performance, clears, latency, and recovery depend on the session and system. The GPU watchdog responds to software-visible telemetry and supplements hardware protection.

Live training and calibration use compute resources and can control the foreground game through ordinary keyboard input. An emergency stop can discard updates since the last completed save. The warranty disclaimer and liability terms are set out in the [MIT License](LICENSE).
